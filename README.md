# MPMC Lab Programs

A collection of 8086 Assembly Language programs written for the MPMC lab.

## Program List

| # | File | Description |
|---|------|-------------|
| 1 | 1.asm | Take input from user and display output |
| 2 | 2.asm | Addition of two numbers |
| 3 | 3.asm | Subtraction of two numbers |
| 4 | 4.asm | Multiplication of two numbers |
| 5 | 5.asm | Division of two numbers |
| 6 | 6.asm | Sum of N numbers using a loop |
| 7 | 7.asm | Find smallest number between two numbers |
| 8 | 8.asm | Find smallest number among three numbers |
| 9 | 9.asm | Find largest number among three numbers |
| 10 | 10.asm | Print triangle pattern using asterisks |
| 11 | 11.asm | SHL (Shift Left) instruction |
| 12 | 12.asm | SHR (Shift Right) instruction |
| 13 | 13.asm | ROL (Rotate Left) instruction |
| 14 | 14.asm | ROR (Rotate Right) instruction |

## Tools Used
- Assembler: EMU8086
- Architecture: 8086# MPMC
